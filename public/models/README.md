# Resume film assets

`macbook.glb` is a Blender conversion of Apple's silver 16-inch MacBook Pro M3 Pro USDZ, linked in the reference tweet (https://x.com/wiedymi/status/2097311356580233228).

Source: https://www.apple.com/105/media/us/macbook-pro/2023/232a2dbf-5898-4fd1-a350-6a7c5c2e31c9/ar/macbook_pro_m3_pro_16_silver.usdz

Downloaded September 8, 2026. Original model belongs to Apple. Used here for the local branch experiment; this note does not grant redistribution rights.

Camera meshes in `gear/` are the existing portfolio assets. Photography and product screenshots are reused from `src/assets`.
